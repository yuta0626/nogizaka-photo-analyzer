# 乃木坂46 生写真 封入パターン分析

開封した生写真の「メンバー」と「ヨリ・チュウ・ヒキ」を記録し、パック構成や同時封入傾向を分析する静的Webアプリです。

## 使い方
1. `index.html` をブラウザーで開くか、GitHub Pagesで公開します。
2. メンバー名と期別は公式サイトを参考に初期設定済みです。必要に応じて「設定・データ」で編集します。
3. 「開封記録」で各パックの5枚を入力します。
4. 各パックで「表紙メンバー」を選びます（5枚の中に実際に含まれるメンバーを選択）。
5. 「全体分析」「メンバー分析」「期別分析（今回の版では省略）」「同時封入分析」「表紙メンバー分析」「パック比較」を確認します。
5. 「設定・データ」からJSON/CSVをエクスポートしてバックアップできます。

## GitHub Pagesで公開する方法
1. GitHubで新しいリポジトリを作成します（例: `nogizaka-photo-analyzer`）。
2. このフォルダーの `index.html` と `README.md` をリポジトリ直下にアップロードします。
3. リポジトリの **Settings → Pages** を開き、Build and deployment の Source を **Deploy from a branch** にします。
4. Branch を `main`、フォルダーを `/(root)` にして Save。
5. 公開処理後、Pages画面に表示されたURLからアクセスします。

## 保存・プライバシー
- 記録はブラウザーの `localStorage` に保存されます。サーバーへ送信する機能はありません。
- ブラウザーや端末を変える場合は、JSONをエクスポートして移行先で読み込んでください。
- GitHub Pages上で使う場合も、同じブラウザー・同じサイトURL内で保存されます。

## 分析項目
- ヨリ・チュウ・ヒキのパック別構成
- メンバー別封入枚数、出現パック数、ポーズ内訳
- 期別の封入枚数、所属メンバー数、1人あたり平均、ポーズ内訳
- パック内の期別構成と期別ペアの同時封入傾向
- 同時封入ペア、条件付き出現割合、独立仮定時の期待回数との比較
- 同時封入マトリクスと未観測ペア
- 表紙メンバーごとに、表紙カード1枚を除いた残り4枚のメンバー同封率・ポーズ構成・期別構成を分析
- 表紙メンバーと残り4枚の同封パターン比較
- パックごとの重複、共通メンバー数、Jaccard類似度
- JSON/CSVバックアップ

## 注意
表紙分析では、各パックの「表紙メンバー」を指定してください。表紙メンバーがそのパックの記録済みカードに含まれていない場合、そのパックは表紙分析から除外されます。10パックではデータが少なく、見かけ上の偏りが偶然である可能性があります。「一緒に出なかった」ことは封入仕様上の排他を意味しません。また、次パックの出現確率を保証するものではありません。


今回の更新では、期別分析機能を削除し、表紙メンバー別の残り4枚の分析を中心にしています。
