GitHub Pages で公開する場合は、このフォルダ内の `index.html` をリポジトリの `index.html` と差し替えてください。

今回の変更:
- 所持一覧の＋／−ボタンの間隔とタップ領域を拡大
- 所持一覧のメンバー名を期別に色分け（3期生=水色、4期生=オレンジ、5期生=ピンク、6期生=緑）

- 所持一覧を縦スクロールしたときに見出し行を固定。横スクロール時はメンバー列も固定

差し替え前に、アプリの「設定・データ」からJSONバックアップを保存してください。ブラウザ内の既存データは、HTMLを差し替えただけでは通常消えません。
