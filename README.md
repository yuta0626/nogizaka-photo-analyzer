# 乃木坂46 生写真分析アプリ 修正版

## 反映方法
1. 現在のアプリの「設定・データ」からJSONバックアップを保存してください。
2. このZIP内の `index.html` をGitHubリポジトリ内の既存 `index.html` と置き換えてコミットしてください。
3. GitHub Pagesの更新後、ブラウザーで再読み込みしてください。

## 今回の変更
- 1パック内で同じメンバーを重複選択できないようにしました。
- 「シリーズごとのポーズ設定」を「開封記録」タブへ移動しました。
- 開封記録タブ上部でシリーズ選択と、そのシリーズの開封結果の表示／非表示切り替えができます。
- 既存のシリーズデータ・記録データの保存形式は維持しています。
