# 乃木坂46 生写真 封入パターン分析

`index.html` をブラウザーで開くか、GitHub Pages のリポジトリに配置してください。

## 今回の更新
- お気に入りに設定したメンバーの開封記録のメンバー欄を黄色で表示
- 設定・データに「シリーズごとのメンバー設定」を追加
- シリーズごとにメンバー一覧を1行ずつ設定し、開封記録の選択肢と所持生写真一覧に反映
- 既存データのシリーズには、これまでの全体メンバー一覧を初期値として引き継ぐ

データはブラウザーの localStorage に保存されます。GitHub Pages への公開はファイルをリポジトリに反映する必要があります。
