# 乃木坂46 生写真 封入パターン分析

乃木坂46の生写真パックをシリーズごとに記録し、全シリーズを合算して封入傾向を分析する静的Webアプリです。

## 使い方
1. `index.html` をブラウザーで開くか、GitHub Pagesで公開します。
2. 「開封記録」の「シリーズ管理」で、記録するシリーズを選びます。
3. 新しいシリーズを記録するときはシリーズ名を入力して「新規シリーズを追加」を押します。
4. 選択中のシリーズについて、各パックの5枚のメンバーとポーズ（ヨリ・チュウ・ヒキ）を入力します。
5. 各パックの1枚目に表紙メンバーを入力します。表紙メンバーは自動判定され、2〜5枚目の残り4枚を分析します。表紙メンバーを別途選択する必要はありません。
6. 「全体分析」「メンバー分析」「同時封入分析」「表紙メンバー分析」「パック比較」では、シリーズを問わず記録済みデータを合算して分析します。
7. 「設定・データ」からJSON/CSVをエクスポートしてバックアップできます。

## シリーズの扱い
- 各シリーズの開封記録は別々に保存され、シリーズを切り替えるとそのシリーズの入力内容が表示されます。
- 分析タブでは全シリーズを合算します。シリーズ間で封入条件が異なる場合、集計結果は参考値として解釈してください。
- 「このシリーズの入力を全消去」は現在選択中のシリーズだけを消去し、ほかのシリーズは消去しません。
- CSVにはシリーズ名も出力されます。JSONにはシリーズごとの全記録が保存されます。
- 既存の初期シリーズ「シリーズ1」は、更新版を開くと「フレンチガーリー」に自動変更されます。パックの記録内容は変更・削除されません。旧形式のデータも「フレンチガーリー」として移行します。

## GitHub Pagesで公開する方法
1. GitHubのリポジトリ直下に `index.html` と `README.md` をアップロードします。
2. リポジトリの **Settings → Pages** を開きます。
3. Build and deployment の Source を **Deploy from a branch** に設定します。
4. Branch を `main`、フォルダーを `/(root)` にして Save します。
5. Pages画面に表示されたURLからアクセスします。

## 保存・プライバシー
- 記録はブラウザーの `localStorage` に保存され、サーバーへ送信されません。
- ブラウザーや端末を変える場合は、JSONをエクスポートし、移行先で読み込んでください。
- GitHub Pagesで使う場合も、同じブラウザー・同じサイトURL内で保存されます。

## 分析項目
- 全シリーズ合算のポーズ構成パターンとポーズ別総枚数
- メンバー別封入枚数、出現パック数、ポーズ内訳
- 同時封入ペア、条件付き出現割合、独立仮定時の期待回数との比較
- 同時封入マトリクスと未観測ペア
- 1枚目の表紙メンバーごとの残り4枚のメンバー同封率・ポーズ構成
- シリーズを含むパックごとの構成、共通メンバー数、Jaccard類似度
- JSON/CSVバックアップ

## 表紙メンバーの扱い
各パックの入力欄の1枚目を表紙カードとして扱います。表紙分析では1枚目を除き、2〜5枚目を残り4枚として集計します。1枚目が未入力のパックは表紙分析の対象外です。少数のパックでは偶然の偏りが大きくなる可能性があります。「一緒に出なかった」ことは封入仕様上の排他を意味しません。また、次パックの出現確率を保証するものではありません。
