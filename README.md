# 乃木坂46 生写真 封入パターン分析

## 公開方法
1. GitHub リポジトリ `nogizaka-photo-analyzer` を開く
2. リポジトリ直下の `index.html` をこのZIP内の `index.html` で置き換える
3. Commit changes で保存する
4. GitHub Pages の公開ページを再読み込みする

## 初期状態
- シリーズ：フレンチガーリー
- 初期パック数：10
- 各パック5枚（メンバーとポーズ）
- パック数は1〜500で変更可能
- ブラウザー内にデータを保存

今回の版は、以前の初期化マーカーとは別のマーカーを使い、初回読み込み時に既存記録を一度だけリセットします。GitHub Pagesで新しい `index.html` が公開されるまでは画面に反映されません。
