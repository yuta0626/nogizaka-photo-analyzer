# 乃木坂46 生写真 封入パターン分析

- `index.html` を GitHub Pages のリポジトリ直下に置いて公開してください。
- 開封記録はシリーズ別・各パック5枚で保存されます。
- 「所持生写真一覧」は、開封記録に入力した写真を同じシリーズの一覧へ自動反映します。開封結果が不明な写真だけ、一覧から1枚ずつ手入力してください。所持一覧は開封分析には混ぜません。
- 「設定・データ」からシリーズごとのポーズを3〜5種類に設定できます。
- データはブラウザーの localStorage に保存されます。ブラウザーや端末を変える前にJSONバックアップを保存してください。
