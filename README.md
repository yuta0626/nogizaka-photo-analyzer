# 乃木坂46 生写真管理 修正版 final27

## 変更点
- パック内の同一メンバー重複を分析項目から削除。
- 全体分析の「メンバー重複・パック内の特徴」を、入力状況・シリーズのポーズ種類数・よくあるポーズ構成に変更。
- ポーズ別集計に、対象ポーズが設定されているシリーズのパック数を分母とする出現率を追加。3〜5種類のシリーズを単純比較する際の偏りを読み取りやすくしました。
- パック比較からメンバー重複列を削除し、パックの入力枚数・ポーズ構成・メンバー一覧を表示。
- メンバー分析・同時封入分析の説明文を、各指標の意味が分かるように修正。
