# 乃木坂 生写真分析アプリ 修正版 final25

所持生写真一覧の列幅を調整しました。
- 吉田綾乃クリスティーがいる場合、メンバー列幅を3・4・5ポーズで90pxに統一。
- ポーズ列幅は「吉田綾乃クリスティーがいる5ポーズ表示」を基準に計算し、3・4・5ポーズおよび吉田綾乃クリスティーの有無で同じ幅を使用。
- 以前のCSS幅指定が競合しないよう、最後のルールで列幅を統一。

GitHub Pagesに反映する場合は、リポジトリ内の `index.html` をこの `index.html` で置き換えてください。更新前にアプリの「設定・データ」からJSONバックアップを保存してください。
