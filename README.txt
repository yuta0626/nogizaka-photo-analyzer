乃木坂46 生写真管理 - final41

final40をベースに、iPhoneの所持生写真一覧における固定表示を調整しました。
・シリーズ選択バーをページ上部の固定ナビゲーションの直下に配置
・「メンバー／ヨリ／チュウ／ヒキ」の表見出しを、シリーズ選択バーの直下に追従固定
・ナビゲーションとシリーズ選択バーの実際の高さを取得して固定位置を計算
・メンバー列の左固定を維持

利用方法：index.htmlをGitHub Pagesリポジトリのindex.htmlと置き換えてください。
既存データはブラウザのlocalStorageに保存されます。更新前にアプリの設定・データからJSONバックアップを推奨します。
