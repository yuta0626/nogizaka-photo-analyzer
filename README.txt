乃木坂生写真分析アプリ 修正版 final14

更新内容
1. 所持生写真一覧で選択したシリーズIDを保存データに含め、ブラウザの再読み込み後も同じシリーズを表示します。
2. 所持生写真一覧の「吉田綾乃クリスティー」を「吉田綾乃」「クリスティー」の2行表示にしました。名前欄の高さをロック・お気に入りアイコンの高さに合わせ、他メンバーと行高が揃うようにしています。

適用方法
1. 現在のアプリで「設定・データ」からJSONバックアップを保存してください。
2. ZIPを展開し、index.htmlをGitHubリポジトリ内のindex.htmlと置き換えてコミットしてください。
3. GitHub Pagesの更新後にページを再読み込みしてください。
